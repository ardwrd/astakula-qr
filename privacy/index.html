Privacy Policy

This page explains how the current Astakula Tools implementation handles tool inputs, browser preferences, and external network requests.

Effective date: October 3, 2026 · Developer: Ariyo Ardiwardana · Parent brand: Astakula

1. Scope

This Privacy Policy applies to the public website at tools.astakula.com. Astakula Tools is a collection of browser-based utilities developed by Ariyo Ardiwardana under Astakula.

2. Tool inputs and processing

The current repository does not contain an Astakula application backend, account system, or database for storing tool inputs. QR, JSON, Base64, UUID, hash, image, PDF, GIF, favicon, and spreadsheet operations are implemented in the browser.

Network Tools also performs its subnet, range, IPv4, MAC, bandwidth, and port-reference operations in the browser. The DNS Inspector is different: when you run a DNS lookup, the requested domain and record type are sent to Cloudflare's public DNS-over-HTTPS resolver so the lookup can be completed.

3. Local browser storage

Astakula Tools stores the selected light or dark theme preference in your browser's localStorage. This preference remains on the device until it is changed, cleared by the browser, or otherwise removed by the user.

4. External libraries and delivery services

Some pages load browser libraries and the shared UI package from jsDelivr. Examples in the current source include QR rendering, PDF processing, GIF encoding, ZIP creation, and spreadsheet parsing libraries. Loading these assets creates normal web requests to the external delivery service; tool input is not intentionally sent to jsDelivr by the Astakula Tools application code.

5. Hosting and connection data

Like other public websites, requests for pages and assets can expose standard connection information such as an IP address, user agent, requested URL, and request time to hosting, CDN, DNS, or network providers involved in delivering the site. Those providers operate under their own terms and privacy practices.

6. Analytics, advertising, and application cookies

No analytics service, advertising tracker, account login, or application-level tracking cookie was identified in the current repository during the October 2026 source audit. If these systems are added later, this policy should be updated before relying on the current statement.

7. Downloads and generated output

Generated files are created for you to download. You are responsible for where downloaded files are stored, shared, or uploaded after they leave the browser workflow.

8. Changes to this policy

This policy may be revised when the tools, data flows, hosting setup, or external services change. The effective date above indicates the version represented by this page.

9. Contact

For questions about Astakula Tools, use the contact information published by Astakula.
