At a glance

The main privacy behavior of the current public implementation can be summarized in three points.

Most tools Process input inside the browser.
DNS Inspector Sends the requested domain and record type to Cloudflare DNS-over-HTTPS.
Browser storage Saves the selected light or dark theme in localStorage.
01

Scope

This Privacy Policy applies to the public website at tools.astakula.com. Astakula Tools is a collection of browser-based utilities developed by Ariyo Ardiwardana under Astakula.

This page describes the behavior verified from the current project source. If the implementation or hosting stack changes, the policy should be reviewed again.

02

How tool inputs are processed

The current repository does not contain an Astakula application backend, account system, or database for storing tool inputs.

03

Local browser storage

Astakula Tools stores the selected light or dark theme preference in the browser's localStorage. That preference remains on the device until it is changed, cleared by the browser, or otherwise removed by the user.

04

External libraries and delivery services

Some pages load browser libraries and the shared UI package from jsDelivr. Current examples include libraries used for:

  • QR code rendering;
  • PDF processing;
  • GIF encoding;
  • ZIP creation; and
  • spreadsheet parsing and writing.

Loading those assets creates normal web requests to the external delivery service. Astakula Tools application code does not intentionally send the contents of tool inputs to jsDelivr.

05

Hosting and connection data

Requests for pages and assets can expose standard connection information—such as an IP address, user agent, requested URL, and request time—to hosting, CDN, DNS, or network providers involved in delivering the website. Those providers operate under their own terms and privacy practices.

06

Analytics, advertising, and application cookies

No analytics service, advertising tracker, account login, or application-level tracking cookie was identified in the current repository during the October 2026 source audit.

If analytics, advertising, authentication, or additional tracking is introduced later, this statement should be updated before the new behavior is relied upon.

07

Downloads and generated output

Generated files are created for you to download. You are responsible for where downloaded files are stored, shared, or uploaded after they leave the browser workflow.

08

Changes to this policy

This policy may be revised when the tools, data flows, hosting setup, or external services change. The effective date shown on this page identifies the version currently represented here.

09

Contact

For questions about Astakula Tools or this Privacy Policy, use the contact information published by Astakula.
