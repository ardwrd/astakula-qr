What is a social grid preview?

A grid preview is a planning view that shows how several images look together in a three-column arrangement. It helps compare color balance, visual rhythm, and post order before publishing.

How to use it

  1. Add several images.
  2. Use the up and down controls to change their order.
  3. Review the three-column preview and export a PNG reference if needed.

Frequently asked questions

Does this connect to Instagram?

No. The current tool does not log in, publish posts, or read account data. It only previews the images you provide.

Are my images uploaded?

No Astakula application backend is used by this tool. The current preview and export workflow runs in the browser.

Why are thumbnails square?

The preview uses square tiles as a simple profile-grid planning view. Your original files are not modified unless you export the combined preview PNG.
