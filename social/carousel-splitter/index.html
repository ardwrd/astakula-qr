What is a carousel splitter?

A carousel splitter divides one continuous image into separate panels that can be posted in sequence. It is useful for seamless layouts where graphics or photos continue across multiple slides.

How to use it

  1. Upload the full-width carousel design.
  2. Choose portrait, square, or landscape output and set 2–10 slides.
  3. Split the image, review each panel, then download individual files or the ZIP.

Frequently asked questions

Does Astakula upload my image?

No Astakula application backend is used by this tool. Splitting is performed in the browser.

Which formats can I export?

JPEG, PNG, and WebP are supported by the current export workflow.

Why can the edges be cropped?

If the source aspect ratio does not match the full carousel canvas, Cover mode fills the canvas by cropping excess edges. Use Contain mode to preserve the complete source.
